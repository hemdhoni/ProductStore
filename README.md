# Product Store 🛍️  
This is a full-stack Product Store application built using **React** (frontend), **Node.js** (backend), and **PostgreSQL** (database). The application allows you to add, edit, and list products with their details. It also displays the total count of available products.

---

## Features ✨  
- Add new products 📦  
- Edit existing product details ✏️  
- View a list of all products 📋  
- Get the total number of products available in the store 🔢  

---

## Tech Stack 🛠️  
- **Frontend:** React  
- **Backend:** Node.js (Express)  
- **Database:** PostgreSQL  

---

## Prerequisites 🛑  
Make sure you have the following installed:  
- Node.js (v14+ recommended)  
- PostgreSQL
